# گزارش پروژه Site2 — کارآفرینک

## هدف
تکمیل ساختار و صفحات سایت کارآفرینک به‌صورت استاتیک و مستقل از WordPress، سپس انتقال نسخه تأییدشده به WordPress.

## مسیر پروژه
- مخزن: `samadkarami-boop/KARAFARINAK-WEB-Demos`
- مسیر اصلی Site2: `Site2/`
- مسیر Preview: `Site2/Preview/`
- نسخه مرجع استاتیک تأییدشده: `theme-preview/`
- مخزن WordPress واقعی: `samadkarami-boop/Karafarinak-wordpress` (خصوصی)

## برنامه اجرایی

### مرحله ۱ — تکمیل ساختار سایت در Site2
در این مرحله سایت کاملاً استاتیک و بدون وابستگی به WordPress تکمیل می‌شود.

1. تعیین و تکمیل ساختار منو و صفحات
2. ساخت تمام صفحات اصلی
3. تکمیل صفحات محصولات و دسته‌بندی‌ها
4. ساخت صفحات قالب‌های سایت
5. ساخت صفحات آموزش و منابع
6. ساخت صفحه فریلنسری / خدمات
7. تکمیل صفحات تماس، درباره ما و درخواست پروژه
8. یکپارچه‌سازی هدر، فوتر، منو و Navigation
9. پیاده‌سازی نسخه Responsive برای موبایل و دسکتاپ
10. تکمیل فرم‌ها و تعاملات نمایشی
11. ایجاد لینک‌دهی صحیح بین صفحات و ساختار URL
12. بررسی یکپارچگی ظاهری و محتوایی تمام صفحات

### مرحله ۲ — تست کامل نسخه استاتیک
پس از تکمیل صفحات، نسخه Site2 از نظر موارد زیر بررسی می‌شود:

- لینک‌های خراب و مسیرهای اشتباه
- صفحه 404
- عملکرد فرم‌ها
- نمایش در موبایل و دسکتاپ
- تصاویر و فایل‌های وابسته
- سرعت و حجم صفحات
- SEO پایه
- RTL و نمایش صحیح فارسی
- مسیر محصولات و سبد خرید
- مسیر ثبت سفارش / درخواست پروژه

### مرحله ۳ — انتقال به WordPress
پس از تأیید نسخه استاتیک، ساختار و ظاهر نهایی آن مبنای پیاده‌سازی WordPress قرار می‌گیرد.

روند:
`Site2/Preview`
→ نسخه نهایی استاتیک
→ `samadkarami-boop/Karafarinak-wordpress`
→ WordPress Theme + WooCommerce + قابلیت‌های واقعی

## اصول مهم
- WordPress قبل از تثبیت ساختار نهایی Site2 وارد پروژه نمی‌شود.
- طراحی تأییدشده مبنای تبدیل به WordPress خواهد بود.
- کد واقعی WordPress در مخزن خصوصی `Karafarinak-wordpress` نگهداری می‌شود.
- Site2 برای توسعه، بررسی و Preview نسخه استاتیک استفاده می‌شود.
- هیچ فایل یا کد خصوصی WordPress بدون درخواست صریح در مخزن عمومی قرار نمی‌گیرد.
